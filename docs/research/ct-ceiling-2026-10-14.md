# CT 천장 측정 (2026-10-14)

이 판(1분봉 롱 전용 단타, 비용 후)에 우위가 존재할 수 있는가의 상한을 모델 비용 0으로 잰 결과다. 생성: `scripts/research/ct-ceiling.ts`, 함수: `lib/ct-moves.ts`.

## 방법

- **라벨**: 1분봉 매 시점 t에 t+1 시가 진입을 가정한다. 보유 상한 H(당일 경계를 넘지 않음) 안에서 수익이 +3×왕복비용에 먼저 닿고 −1×왕복비용에 닿지 않았으면 양성이다. 같은 봉에서 둘 다 닿으면 손절 먼저, 불리한 갭은 시가 체결(엔진 `ctExit`와 같음). 코인의 하루는 UTC 00:00(KST 09:00), 주식은 정규장 종료이며 마지막 1분 봉은 신규 진입·청산에 쓰지 않는다(`ctSessionClosing`과 같은 규칙).
- **실현 결과**: 같은 규칙(손절 −m×비용, 목표 +k×비용, 보유 상한 또는 당일 마감 종가 청산)으로 체결했을 때의 총수익에서 왕복 비용을 뺀 값. 라벨과 결과가 한 번의 순회에서 나온다.
- **피처 31개**: DSL 10개 × {1분 30봉, 1시간 24봉, 일봉 10봉} + 시간대(분). 상위 봉은 완성된 것만 쓴다. 주식 1분 피처는 세션 안 연속 봉만, 상위 봉은 이전 세션까지 이어 쓴다.
- **검증**: 깊이 ≤ 3 분류 트리(잎 최소 표본 = 학습 구간 일수 이상, 학습 표본은 N분마다 1개). 전체 기간을 일 단위로 5블록으로 나눠 **확장 창 워크포워드 4폴드**(블록 0..f 학습 → 블록 f+1 검증, 검증 블록 시작 전에 닫히지 않은 학습 거래는 제외). 잎은 **학습** 구간의 평균 순결과가 양수일 때 선택. 검증 구간에서 포지션 하나씩 순서대로 거래한다.
- **지표**: 거래당 순수익(%)은 포지션 명목 대비. 일평균은 검증 구간 모든 날(무거래일 0)의 일별 거래 순수익 합의 평균(포지션 명목 100% 기준; 계약의 배분 25%면 ×0.25). "비용 2배" 열은 같은 거래를 왕복 비용 2배로 다시 계산한 값이다.
- **학습 최고 잎**: 각 폴드의 학습 구간(표본 내)에서 가장 좋았던 잎의 거래당 평균 순결과의 최댓값. 0보다 작으면 이 피처로는 학습 구간에서조차 비용을 넘는 잎이 없었다는 뜻이며(그래서 선택 거래가 0), 이 값이 이 판의 표본 내 천장이다.
- **비용 행**: 현재 계약 비용 / 실측 프로필 / 각각의 2배(라벨의 임계값도 그 비용으로 다시 계산).
- 데이터: 코인 BTCUSDT 2023-10-13 → 2026-10-12, NVDA 2024-10-14 → 2026-10-09. 코인 실측 왕복 비용 0.2000% = 수수료 0.1%×2 + 실측 호가 충격(44 snapshots, p90 side impact 0.0006 bp); 주식은 호가 실측이 없어 현재 계약 비용(Toss)만 쓴다.
