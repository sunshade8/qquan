# CT 천장 측정 확장: 판을 넓히면 비용 후 우위가 있는가 (2026-10-14 사전 등록)

`docs/prompts/ct-stage4-field-and-eye.md` 2.7의 결과 문서다. 모델 비용 $0.
**이 절은 측정을 돌리기 전에 쓰고 커밋했다. 결과를 본 뒤 아래 기준을 바꾸지 않는다.**
(파일 이름: 같은 날짜의 3단계 기준선 `ct-ceiling-2026-10-14.md`가 이미 있어 `-field`를 붙였다.)

## 0. 사전 등록 (측정 전)

### 0.1 판정 기준 (지시서 2.7 그대로)

조합이 **"유료 연구 후보"**가 되려면 다음을 모두 만족해야 한다.

- 비용 1배 워크포워드 일평균 > 0
- 양수 폴드 ≥ 3/4
- 선택 거래 ≥ 0.27건/일 (개발 구간 73일에서 게이트 최소 20건)
- 비용 2배 일평균 > 0
- 아래 순열 기준선을 통과

**순열 기준선:** 위 네 조건을 만족한 조합에만 적용한다. 일 단위 블록으로 피처 행을 섞는 순열을 20회
돌리고, 실제 일평균 이상이 나온 횟수를 보고한다(20회 중 1회 이하일 때 통과).

### 0.2 측정 방법 (바꾸지 않는다)

`docs/research/ct-ceiling-2026-10-14.md`와 같다: 1분봉 매 시점에서 다음 봉 시가 진입, +3×왕복비용 대 −1×왕복비용,
보유 상한 {60, 240, 390봉, 당일 청산}(당일 경계 비월경, 코인 UTC 00:00), 31개 피처
(DSL 10개 피처 × {30×1분, 24×1시간, 10×일봉} + 하루 중 분), 확장 창 워크포워드 4폴드(경계에서 퍼지),
깊이 ≤ 3 트리(잎 최소 표본 = 학습 일수 이상), 잎 선택 = **학습 구간** 비용 후 평균 > 0,
일평균 = 평가 구간 모든 날의 선택 거래 순수익 합의 평균(무거래일 0), 비용 2배 열 = 같은 거래를 비용 2배로 다시 계산.
라벨·트리·폴드 코드는 `lib/ct-moves.ts` 그대로이며, 이번 변경은 (a) 종목·기간·비용·가격 경로의 조합 추가,
(b) 피처 열 추가(ablation), (c) 순열 기준선 추가뿐이다.

### 0.3 조합의 정의

한 **조합** = 종목 × 기간 × 보유 상한 × 비용 시나리오 × 피처 집합 × 가격 경로.

| 축 | 값 |
|---|---|
| 종목 | BTCUSDT, ETHUSDT, SOLUSDT (Binance 현물 1분봉) |
| 기간 | 1년, 3년 (BTC는 5년 한 줄 추가) — 모두 최근 종료일 기준 |
| 보유 상한 | 60봉, 240봉, 390봉, 당일 청산 |
| 비용 시나리오 | **B-1** Binance 실측 프로필(종목별, 수수료 0.1%×2 + `ct_orderbook_samples` 실측 p90 충격, 잠정) / **B-2a** Upbit 비용(수수료 0.05%×2 + Upbit 실측 스프레드·충격, `upbit-krw` v2)을 Binance 가격 경로에 적용 / **B-2b** Upbit 1분봉 가격 경로 + Upbit 비용 |
| 피처 집합 | **F1** 가격·거래량 31개(현재) / **F2** F1 + 파생(펀딩, 프리미엄, 미결제약정, 테이커 비율, 청산) / **F3** F2 + Upbit–Binance 괴리·선후행 |
| 가격 경로 | Binance(B-1, B-2a) / Upbit(B-2b; 괴리 피처 F3는 Upbit 경로에서만 정의) |

"비용 1배" = 그 조합의 비용 시나리오 값, "비용 2배" = 그 값의 두 배(보고서의 `2x` 열).
F2·F3의 파생·괴리 데이터는 **파생 데이터가 실제로 있는 기간**(3년 이내)에서만 잰다(없는 항목은 "제공 안 됨").
기간별 결과 외에 **국면별**(일봉 SMA200 위/아래 날짜의 일평균)을 따로 보고한다 — 후보 판정에는 쓰지 않는다.

### 0.4 시점 규칙 (미래 값 금지)

결정 시각 t(= 봉 마감 `endMs`)에서 이미 공개된 값만 쓴다.
5분 지표는 **완성된 구간**(구간 끝 ≤ t)만, 펀딩비는 **정산 시각 이후**에만, 프리미엄 지수 1분봉은 완성된 분만,
괴리는 같은 분의 완성 봉 종가로 계산한다. 타임스탬프의 의미(구간 시작/끝)는 실제 파일로 확인한 뒤 적용하고
`tests/ct-ceiling-features.test.mjs`가 "결정 시각 이후 값을 오염시켜도 피처가 같다"를 고정한다.

### 0.5 보고할 반복 검정 수

조합 수 × 폴드 4 × 피처 수(F1 31 / F2 / F3) 와 트리가 평가한 후보 분할 수. 판정 기준을 통과한 조합 수와,
**우연히 통과한 조합 수의 기댓값**(순열 기준선의 실제 통과율로 추정)을 함께 적는다.
결론은 "유료 연구 후보 있음: 조합 …" 또는 "후보 없음"과 그 근거, 둘 중 하나다. 어느 쪽이든 정상이다.

### 0.6 하지 않는 것

파생·괴리 피처를 DSL이나 설계 도구에 넣지 않는다. 후보가 나와도 결과만 보고하고 다음 단계는 소유자가 정한다.
백그라운드 호가 샘플러(`npm run data:orderbook -- --hours=72`, 2026-10-16 17:41Z 종료 예정)는 멈추지 않는다 —
이 보고서는 그 시점까지 쌓인 표본을 쓰며 프로필은 **잠정(provisional)**이다.

### 0.7 보충 정의 (측정 전에 추가·커밋, 판정 기준은 0.1 그대로)

데이터 제공 범위를 실제 파일로 확인한 뒤(2026-10-14 19:00–19:40 KST, 아래 1절 표) 측정 코드를 쓰기 전에 적은 정의다. 결과를 본 뒤 바꾸지 않는다.

- **기간 정의.** 종료 = 2026-10-13 00:00 UTC. 1년 = 365일(2025-10-13부터), **3년 = 파생 데이터가 시작하는 2023-11-01부터 현재까지(1,078일)**, BTC 5년 = 1,826일(F1만). 3년을 파생 데이터 시작일로 맞춘 것은 F1·F2·F3의 행 집합을 같게 해 피처 집합 비교(ablation)를 공정하게 하려는 것이다(파생이 없는 구간의 행은 어차피 학습에서 빠진다).
- **F2 파생 피처 11개** (결정 시각 t = 1분봉 마감 `endMs`, 값은 t까지 **공개된** 것만):
  `funding_level`(t 이전 마지막 정산 `calcMs ≤ t`의 펀딩비), `funding_change`(직전 정산 대비 변화), `premium_pct`(완성된 1분 프리미엄 봉 `endMs ≤ t`의 종가×100), `premium_chg15`·`premium_chg60`(15·60분 전 완성 봉 대비 변화), `premium_z7d`(7일 1분 값의 z점수), `oi_chg60`·`oi_chg240`(미결제약정 가치의 60·240분 변화율 %), `oi_z7d`(7일 z점수), `taker_ratio`(마지막 완성 5분 구간의 테이커 매수/매도 거래량비), `taker_ratio_1h`(최근 완성 12개 구간 평균). 5분 지표 `create_time = T`는 구간 **시작**이고 값은 [T, T+5분)을 요약한다(실제 선물 1분봉의 테이커 비율과 대조해 확인: 이 구간과 중앙 로그오차 0.0002, 구간 끝으로 읽으면 0.46). 그래서 `T + 5분 ≤ t`인 구간만 쓴다. 청산 규모는 **제공 안 됨**(아카이브에 UM `liquidationSnapshot` 없음, REST `allForceOrders` 이력 중단)이라 뺀다.
- **F3 괴리 피처 7개**: `gap_pct`(Upbit 종가 ÷ (Binance 종가 × Upbit KRW-USDT 종가) − 1, ×100), `gap_chg15`·`gap_chg60`, `gap_z7d`, `lead1`·`lead3`·`lead5`(Binance 직전 1·3·5분 수익률 − Upbit 같은 구간 수익률, %p). 모두 같은 분의 완성 봉 종가로 계산한다.
- **Upbit 빈 분.** 거래가 없던 분은 API가 봉을 주지 않는다. 가격 경로에서는 직전 종가의 평평한 0거래량 봉으로 채운다(거래되지 않은 가격은 움직이지 않았다). 채운 분 수를 보고한다. 앞쪽(첫 봉 이전)은 채우지 않는다.
- **비용.** B-1 = 0.1%×2 + 2 × (그 종목의 `ct_orderbook_samples` Binance $1,000 편도 충격 p90). B-2a/b = 0.05%×2 + 2 × (Upbit 같은 종목 $1,000 편도 충격 p90). 둘 다 샘플러가 끝나기 전의 **잠정** 값이다(`ct_orderbook_samples`의 현재 표본 수를 표에 적는다).
- **순열 기준선 구현.** 하루 단위 블록: 날짜들을 시드 고정 순열로 섞어, 각 날의 피처 행(같은 분 위치)을 다른 날의 피처 행으로 바꾼다(라벨은 그대로). 20회, 시드 = 조합 id 해시. 결과의 `dailyMean ≥ 실제 일평균`인 횟수를 보고한다.

- **반복 검정 수.** (조합 수 × 폴드 4 × 피처 열 수)와 트리가 평가한 후보 분할 수의 합을 보고한다.

## 1. 결론

**후보 없음.** 측정한 140개 조합 중 사전 등록 기준(비용 1배 일평균 > 0, 양수 폴드 ≥ 3/4, 선택 거래 ≥ 0.27건/일, 비용 2배 일평균 > 0)을 **모두** 만족한 조합은 0개이고, 순열 기준선까지 통과한 조합은 0개다.

기준별 통과 조합 수(전체 140개): 비용 1배 일평균 > 0 → 2개 · 양수 폴드 ≥ 3/4 → 0개 · 선택 거래 ≥ 0.27건/일 → 28개 · 비용 2배 일평균 > 0 → 2개. 거래가 아예 선택되지 않은 조합(학습 구간에서 비용 후 양수인 잎이 없음) 64개, 선택은 됐지만 검증 구간 일평균이 음수인 조합 74개, 일평균이 양수인 조합 2개.

**읽는 법(해석).**
- 판을 넓혀도(종목 BTC·ETH·SOL, 기간 1·3·5년, Upbit 가격 경로와 비용, 파생·괴리 피처) 기준을 통과하는 조합이 없다. 일평균이 양수인 조합 2개는 선택된 거래가 1, 1건뿐(거래/일 0.00)이라 양수 폴드 1/4에 그친다.
