## R1. 3일 급락 단기 반전 (H2) — 조건부 채택

**페이퍼 원장 태그**: `h2-3day-reversal`

### 기계 규칙

```
유니버스: megacap ∪ nasdaq_tech (57종목, lib/universe.ts)

매일 종가 확정 후:
  후보 = { s ∈ 유니버스 : close[s,t] / close[s,t-3] - 1 <= -0.06 }
  # SMA200 필터는 쓰지 않는다. 검증에서 성적을 낮췄다.

  정렬(후보, 3일 수익률 오름차순)          # 낙폭이 큰 종목 우선
  선택 = 상위 3종목                        # 하루 최대 3건. 상한이 용량 제약이자 분산 장치
  각 선택 종목에 대해:
     진입 = 다음 거래일 종가 (MOC)
     사이즈 = 총자본의 1/12
     손절 = 진입가 × 0.94                  # -6% 고정, 장중 판정
     청산 = 손절 도달 / 진입 후 5거래일째 종가, 둘 중 먼저
     익절 없음                             # 3·4·6% 익절 모두 성적을 낮췄다
```

동시 보유 상한은 12건(자본 100%). 상한에 걸리면 그날 신규 진입은 건너뛴다.

### 실측 성적 (2015-09 ~ 2026-09, 11년, 하루 3종목 상한)

|---|---|

| 평균 이익 / 평균 손실 | +6.40% / −4.58% (**손익비 1.40**) |
| 거래당 순수익 | **+0.852%** |
| 풀링 t / **날짜 클러스터 t** | 9.77 / **4.64** |
| 활성일 | 1,495 / 2,765세션 = **54.1%** |

| 슬롯 1/12 기준 기대 일수익 | **+0.082%** |

### 이 규칙을 끄는 조건 (사전 등록)

1. **롤링 250거래 클러스터 t가 0 아래로 내려가면 중단.** 2020–2022 구간에서 실제로 그랬다(클러스터 t −0.70).
2. **롤링 100거래 승률이 43.4%(손익분기) 아래로 3주 연속이면 사이즈 절반.**
3. **QQQ가 SMA200 아래이고 20일 실현변동성이 상위 20%면 신규 진입 중단.** 이 규칙이 죽는 국면은 "회복이 느린 하락장"이다.
4. **하루 3종목 상한을 늘리지 않는다.** 상한 5로 늘리면 거래당 순수익은 +0.938%로 올라가지만 같은 날 상관 1인 포지션이 5개가 되어 낙폭이 커진다.

### `lib/strategy.ts` 사양 (엔진에 그대로 넣는 형태)

```ts
entry:   [{ left: { kind: "return", period: 3 }, op: "<=", right: { kind: "value", value: -6 } }]
exit:    []
holding: { maxSessions: 5, stopLossPct: 6, takeProfitPct: null }
sizing:  { mode: "equal_weight" }
costBps: costBps()   // 11.54 = 왕복 0.2308%의 편도
```

`scripts/research/h2-spec-check.ts`로 실행 확인함 (`out/h2-spec.json`).
엔진 결과: 거래 3,966건, 승률 54.6%, 거래당 +1.088%, 노출 **12.6%**, Sharpe 0.58, MDD −14.8%, OOS CAGR +6.7%.

**교란 검사** (엔진이 자동으로 돌린다):

| 교란 | 순 CAGR% | Sharpe | MDD% |
|---|---|---|---|
| 기준 | 5.14 | 0.58 | −14.8 |
| 지표 기간 ×0.8 | 4.62 | 0.58 | −13.3 |
| 지표 기간 ×1.2 | 6.49 | 0.69 | −12.1 |
| **비용 2배 (왕복 0.4616%)** | **3.64** | 0.43 | −15.2 |

| OOS (2023-05 ~ 2026-09) | **6.69** | 0.75 | −10.6 |

파라미터를 ±20% 흔들어도, **수수료가 지금의 두 배가 되어도** 양수를 유지한다. 이 규칙의 fee-in-R이 0.038R로 작기 때문이고, 손절을 조이지 말아야 하는 이유이기도 하다.

**주의**: 엔진 판정은 `inconclusive`이고 `stabilityScore`는 0이다. 둘 다 원인이 같다: 유일한 미달 항목인 "벤치마크 대비 초과 CAGR ≥ 0"에서 엔진 벤치마크가 같은 57종목을 **100% 노출로 상시 보유**한 것이라 **노출 12.6%짜리 규칙과 비교 대상이 아니고**, `stabilityScore`도 같은 초과 CAGR 기준으로 매겨진다. 노출당 수익으로 환산하면 5.14%/0.126 = 40.8%인 반면 벤치마크는 29.9%다. 엔진에 노출 보정 벤치마크가 없다는 것이 이 판정의 원인이며, 규칙의 결함이 아니다. 원장에서는 **노출 대비 수익과 MDD**로 평가한다.
