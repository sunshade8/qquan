# 종목 판 데이터 가능성 (2026-10-17, 읽기 전용 점검, 모델 비용 $0)

키 값은 어디에도 남기지 않았다. 호출은 `https://api.massive.com`(Polygon 의미론), `limit=50000`.

## 1. 질문별 결과

| 질문 | 결과 | 요청 예 → 응답 |
|---|---|---|
| 특정 과거일 전 종목 일봉 (grouped daily) | **부분적: 2024-10-17 이후만** | `/v2/aggs/grouped/locale/us/market/stocks/2026-10-14` → 200, 12,683종목. `2024-10-17` → 200, 10,707종목. `2024-10-16`, `2024-10-15`, `2021-10-15` → 403 `NOT_AUTHORIZED` "past historical entitlements" |
| 상폐 종목이 그 날 자료에 들어 있나 | **됨** (그 날 거래됐다면) | 2024-10-17~2026-10-16 grouped 522일에 서로 다른 종목 16,055개, 그중 창 안에 상폐된 CS·ADRC 1,175개 |
| 상폐 종목 메타(티커·상폐일) | **됨, 과거까지** | `/v3/reference/tickers?market=stocks&active=false&type=CS&limit=1000` → CS 6,648개(상폐일 포함, 예: AABA 2019-10-07), ADRC 314개. `date=2021-01-04` 같은 과거 시점 조회도 200 |
| 상폐 종목의 과거 일봉 | **안 됨** (2024-10-17 이전) | `/v2/aggs/ticker/AABA/range/1/day/2019-01-01/2019-03-01` → 403 "plan doesn't include this data timeframe". AAPL 2019도 동일 |
| 분봉 범위 | **2024-10-17 이후만 (재확인)** | AAPL 1분봉 `2024-10-10`, `2024-10-15` → 403. `2024-10-17` → 200, 1,531봉. 상폐 종목도 창 안이면 받는다(AACB 2026-08-14 → 17봉, 거래가 얇은 SPAC). 소형·고변동주 SNDK 2026-10-14 → 853봉, MSTR 2025-03-12 → 781봉 |
| 플랜·레이트리밋 | **분당 5회, 이전 기록대로** | 연속 호출 시 429가 나오고, 12.5초 간격이면 522일 grouped 수집이 끝까지 통과했다. 응답 헤더에 잔여 한도는 없다. 플랜명은 응답으로 확인되지 않음 |
| Yahoo 일봉으로 상폐 종목 | **안 됨** | `v8/finance/chart` AABA, SIVB, FRC, WE 모두 `No data found, symbol may be delisted` |

## 2. 지금 측정 가능한 판 (비용 $0)

| 판 | 기간 | 편향 | 비고 |
|---|---|---|---|
| 미국 보통주·ADR 전 종목 일봉, 시점별 유니버스 | 2024-10-17 ~ 현재 (약 2년) | 생존자 편향 없음(상폐 종목 포함) | `~/.qquan/research/h2-survivorship/grouped/` 에 522일 저장됨. 조정 종가(분할 반영) |
| 같은 판에서 거래대금·변동성·가격대로 고른 소형·급등주 일봉 | 위와 동일 | 없음 | 분기 재구성 규칙이 있으면 백테스트 가능 |
| 소형 급등주·상폐 종목 1분봉 | 2024-10-17 ~ 현재 | 없음 | 종목당 요청 필요, 분당 5회 제한이라 대량 수집은 느리다(종목-일 1건씩) |
| 대형주 일봉 장기 | 2015 ~ 현재 | **있음**(현재 대형주만) | Yahoo 수정주가 캐시 `scripts/research/cache/`. 편향 크기는 이 판으로 못 잰다 |

## 3. 지금 측정 불가능한 판

| 판 | 이유 | 필요한 것 |
|---|---|---|
| 2024-10 이전 전 종목·상폐 포함 일봉(생존자 편향 없는 장기 검증) | Massive 현 플랜 2년 한도, Yahoo는 상폐 종목 없음 | Polygon/Massive의 역사 데이터 상위 플랜(공개 가격표 확인 필요, 가입 안 함), 또는 CRSP·Norgate·Sharadar 같은 상폐 포함 일봉 제공자 |
| 2024-10 이전 1분봉 | 같은 한도 | 위와 동일 |
| 2015년 당시 대형주 중 지금 목록에서 빠진 종목의 가격 | 명단은 지수 구성 변경 이력으로 구할 수 있으나 가격 출처가 없음 | 상폐 포함 일봉 제공자 |

가격 조사는 이 점검에서 하지 않았다(공개 가격표를 확인하지 않았으므로 금액은 적지 않는다). 가입·결제는 하지 않았다.

## 4. 토스 호가로 소형 급등주 스프레드 읽기 (선택 항목)

**보고만 한다.** 토스 시세·호가 API로 스프레드를 읽기 전용 측정하는 것은 가능한 설계이지만, 토큰을 새로 발급하면 이전 토큰이 폐기되어 실행 중인 dev 서버가 끊긴다(`docs/toss-api.md`). 소유자 확인 전에는 토큰을 발급하거나 호출하지 않았다. 소유자가 기존 토큰 재사용 여부나 재발급 허용을 알려주면 측정을 설계할 수 있다.
