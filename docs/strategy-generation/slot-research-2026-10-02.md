# 슬롯 목표 기반 반복 연구 — 구현 및 실측 검증 (2026-10-02 KST)

실주문 없이 연구·백테스트 시스템을 변경했다. 성공 기준과 비용은 완화하지 않았다. 실제 QQQ/SPY 데이터에서 93개 변형을 시험했으며, 모든 슬롯이 목표 시나리오와 개발 진출 기준에 미달했다. 검증 통과 전략 및 계좌 결합 성과는 없다.

## 변경된 실행 경로

`POST /api/strategy-generation action=research` → `createSlotResearch` → 보유 원본 조회/누락 범위만 보충 → 월별 스냅샷과 날짜 경계·품질 분모·비용 동결 → `advanceSlotResearch` → 네 계열 기준 규칙과 진단별 수정안 → 시간순 학습/개발 리플레이 → 진출 후보·결합 규칙 공동 동결 → 유망 후보만 독립 위험 검토 → 공통 최종 기간과 비용/지연 스트레스 → 독립 결과 검토. 신규 연구는 자동 등록/주문하지 않는다.

- `lib/slot-research.ts`: 후보 언어 재사용, 결정론적 네 계열·수정, 데이터 품질 분모, 진단, 목표 판정, 다중 시도 보정 하한.
- `lib/slot-research-store.ts`: 기존 실행 lease/체크포인트와 연동, 원본 스냅샷, 해시 실험 캐시, 노출 기록, 단계별 예산/계산 상한.
- `app/slot-research-results.tsx`: 슬롯 표, 시나리오별 목표 차이, 모든 시도, 규칙·원장·자본곡선·신호 차단 진단과 JSON 산출물.
- 기존 수동 `action=create` 및 저장된 구형 연구는 호환 유지한다. 구형 연구의 데이터 실패도 성과 탈락으로 소비하지 않고 복구 대기로 바꿨다. 구형 완료 기록에 실측이 없으면 “실측 평가 없음”으로 표시한다.

## 데이터 복구와 조사

기존 로더는 제공 기간을 먼저 잘라 캐시를 배제했고, `step=5`도 1분 원본만 요구했다. 이제 **캐시 coverage 확인 후 누락 다운로드만** 공급자 한도 검사한다. 기본 실전용 로더 계약은 원본 1분을 유지하며, 새 개발 연구는 명시적인 `sourceMinutes=5`로만 네이티브 5분을 읽는다. 5분을 1분으로 변환하거나 빈 봉을 만들지 않는다. 캐시 provider 불일치도 거부한다.

보유 목록 (`outputs/slot-research/inventory.json`):

- DB: QQQ 500세션·95,348봉, SPY 500세션·94,887봉, 2024-09-23–2026-09-21, Massive 수정주가 5분봉. RKLB 21세션·4,015봉, 2026-08-18–2026-09-16.
- `assets/market-data`: QQQ/SPY 월별 압축 파일 50개. 내용이 DB와 모두 정확히 일치한다.
- 연구 파일 캐시: SPY·QQQ·NVDA·AMD·TSLA·PLTR·COIN·TQQQ의 5분봉과 짧은 NVDA 캐시, 총 9개. 파일별 실제 날짜·봉 수·슬롯 품질 개수를 조사했다. TQQQ는 기존 레버리지 제외 정책에 따라 연구에 사용하지 않는다. 이 파일들은 `_load.ts`의 Massive adjusted=true 생성 경로를 확인했으나 파일 자체의 공급자 증명은 없다.
- DB 사건일 자료: 531종목·1,061 종목-세션의 `1m-raw` 및 파생 3/5분봉. 사건 선택 편향 때문에 정상 세션의 발동률 분모로 전용하지 않았다.
- 이전 연구 스냅샷도 조회했다. 과거 파일 연구/모델 학습 노출까지 추적할 수 없으므로 독립성 미확인을 명시한다.

새 실측은 성과를 보기 전에 위 QQQ/SPY 공통 기간을 고정했다. 500개 관측일 중 학습은 2025-12-03까지, 개발은 2025-12-04–2026-04-28, 최종 예약은 2026-04-29–2026-09-21이다. **마지막 구간의 전략 성과는 열지 않았다.** 원본 파일의 가격 보유나 품질 검사와 성과 검증을 구분한다. 현재 유니버스의 과거 자료이므로 생존편향은 제거되지 않았다.

슬롯의 모든 원본 봉이 있어야 정상 세션으로 판정한다. 누락·0거래량·중복·순서·가격 품질 문제를 별도 제외 목록에 기록하며 0% 무거래일로 바꾸지 않는다. 단축장/휴장/무체결의 원인을 확정할 수 없는 세션도 별도 보고한다. 날짜 기준은 보유 지수 일봉과 분봉 관측일 합집합이며, 독립 거래소 달력 완전성을 인증하지 않는다. 전체 500일 기준 제외 수는 프리 전반 183, 프리 후반 5, 개장 0, 추세 0, 점심 5, 오후 5, 마감 5, 애프터 전반 31, 애프터 후반 162이다.

## 목표·설정·검증 계약

운용 자본은 기존 `DASHBOARD_CAPITAL_USD=$1,000`, 슬롯은 기존 9개, 목표 환산은 기존 `slotTarget`을 사용한다. 사용자가 목표와 슬롯을 선택하면 함께 저장하며 목표 슬롯 수와 대상 수의 불일치를 거부한다. 이번 실측에서 목표를 임의로 선택하지 않았으므로 기존 일 목표 1/1.5/2% × 3/5/7/9슬롯의 **12개 시나리오**를 모두 비교했다.

판정 지표는 **정상 세션 시작 잔고 대비 비용 후 수익률의 산술평균**이다. 정상 무거래일 0% 포함, 누락일 제외 수 공개. 거래 발생일 평균, 누적 복리 수익률, 발동률을 따로 보존한다. 슬롯 단독 수익률을 계좌 기여로 합산하지 않는다. 결합 시험은 선택 규칙을 모두 동결한 뒤 `runRelay`의 하나의 잔고·시간순 실행으로만 계산한다. 비교 기준은 현금 유지 0%이다.

기본 설정:

- 슬롯당 최소 8개: 작동 이유가 다른 네 계열 × 기준/진단 수정의 최소 비교 기회. 최대 16개: 계열별 최대 네 변형으로 탐색을 제한한다.
- 실제 진단에 따라 신호 부족은 조건별 차단 횟수와 관측 길이, 비용 잠식은 익절·보유시간과 비용 대비 변동폭, 기간/수익 집중은 거래량 확인·종목 순위, 순수익 미달은 VWAP 회복을 시험한다. 각 부모 후보와 변경 내용·개선/악화를 저장한다.
- 최소 범위 후 최근 8회가 0.005%p 초과 개선을 보이지 않으면 정체. 개선이 멈춘 계열에 추가 시도를 계속 배정하지 않는다. 데이터/실행 오류는 동일 슬롯의 추가 실험을 막고 실측 미완료로 남긴다.
- 백테스트 최대 400회, 로컬 탐색/리플레이 경과 시간 600초. 리플레이는 세션 경계에서도 deadline을 확인하므로 진행 중 계산을 중단할 수 있다. 단일 세션 계산/저장 오버헤드는 즉시 강제 선점하지 않는다.
- LLM $8/16/24는 연구 전체 상한. 개발 설계·탐색은 로컬 계산으로 $0이며, 위험 검토 전에 전체 예산의 35%를 최종 검토용으로 남긴다. 기존 호출 예약·청구 미확인 비용·스트리밍 체크포인트·재개를 유지했다. 예산 소진을 목표로 하지 않는다.
- 학습 20거래, 시험 10거래, 낙폭 12%, 최악 일손실 4%, 준수율 95%, 미체결 신호 20%, 하루 수익 집중 50%와 기존 최종 검증 기준을 유지했다. 개발 선택에는 고정 순차 전후반·HAC 하한 및 최대 시도 수에 따른 보수적 다중 비교 보정을 추가했다. 이는 적응적 선택의 엄밀한 통계 독립성을 증명하는 p-value가 아니다.
- 원본 5분은 개발 연구까지만. 유망해도 1분 원본 기반 실행 검증 없이 최종 통과하지 않는다. 노출 이력이 불명인 자료는 새 연구라는 이유로 독립 미사용으로 인증하지 않는다.

```sh
node --experimental-strip-types scripts/research/audit-slot-data.mjs
node scripts/research/run-slot-research.mjs --out outputs/slot-research/new
node scripts/research/run-slot-research.mjs --replay outputs/slot-research/repeated/run.json --out outputs/slot-research/recheck
```
