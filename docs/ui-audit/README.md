## 2. 새 정보 구조 (CT·T 연구 탭)

연구가 없을 때:

```
[헤더 한 줄]                       [연구|검증|운용]  [주식|코인]
┌ 전략 연구 시작 ──────────────[전략 생성 (primary)]┐
│ 요약 한 줄 · 비용 프로필 한 줄                        │
│ ▸ 선택 설정 (접힘)                                   │
└────────────────────────────────────────────────────┘
(빈 상태: 다음 행동 한 문장)
```

연구가 있을 때 (진행 중이면 상태 바가 sticky):

```
[연구 선택 ▾] [기록 다운로드]
상태 바: ● 연구 종료 12/12 · 경과 · 비용 $/$ · 후보 n/6 · 러너        ← 숫자는 여기에만
(진행 중: 지금 하는 일 한 문장 + 에이전트 카드)
┌ 결과 ─ 통과 전략 없음 · 사유 · 최종 지표 ─────────────[전략 등록 (통과 시만 primary)]┐
▸ 진행 단계와 활동 기록   12/12 · 도구 28 · 모델 18       (진행 중 펼침, 종료 후 접힘)
등록된 전략 (있을 때)
┌ 새 연구 ─────────────────────────────[전략 생성]┐  (결과 아래, 같은 모양)
▸ 연구 상세 기록   설계 세션 2 · 후보 0 · 출처 3          (항상 접힘)
     └ 후보 이력, 근거 차트, 설계 세션, 플레이북, 출처, 부품·북, 고급
```

규칙: 위쪽 = 상태와 결과, 가운데 = 접힌 과정, 아래 = 접힌 참고 자료. 기능은 지우지 않고 접거나 옮기기만 한다.
스테퍼의 한도 미터는 활성 시간만 남기고 비용과 후보는 상태 바 한 곳에만 둔다.

## 3. 결과

- 끝난 CT 연구(NVDA): 약 2,400px → 첫 화면 하나(상세 기록을 모두 펼쳐도 상태와 결과가 맨 위). 모바일 가로 스크롤 없음(CT 연구·검증·운용, 전략, 급등주, T, 설정 모두 375px에서 확인).
- 일시정지된 T 연구에서 지금 하는 일, 에이전트 접힘, 단계·피드 펼침, 새 연구 시작 순서를 확인했다.
- 다크 모드에서 CT 연구 화면을 확인했다. 콘솔 오류는 TradingView 외부 위젯 요청 실패뿐이다.
- `npm run lint` 오류 0, 테스트 603/604(기존 실패 `tests/t-free-models.test.mjs` 그대로, 새 실패 없음).
- `git diff -w`에서 로직 줄(fetch, 훅, 상태, 핸들러 본문) 변경 없음. 옮긴 핸들러는 들여쓰기만 바뀌었다.
